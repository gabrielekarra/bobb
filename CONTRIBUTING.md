# Contributing to Bobb

Read README.md and docs/BOBB.md, then use a branch and pull request. Keep connected-app and action boundaries ahead of side effects, retain the daemon network-isolation tests and add meaningful tests for behavior changes. Do not commit accounts, API keys, SSH identities, model weights, macOS images or personal data. Run the relevant checks from .github/workflows/ci.yml. New UI should use the shared Liquid Glass components and respect reduced transparency. Contributions use the MIT License.
